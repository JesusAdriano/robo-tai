Robô de Testes com uso de Inteligência Artificial para automação de testes web.

## 📋 Sobre o Projeto

O Robio-TAI é um framework de automação de testes que utiliza IA para:
- Navegação inteligente em páginas web
- Preenchimento automático de formulários
- Detecção e análise de erros
- Geração de relatórios detalhados
